## 📂 Casos de Estudio Destacados

### 1. ⚡ Automatización de Documentos y Reportes (ETL)
* **Descripción:** Sistema modular en Python que automatiza la ingesta de archivos Excel, aplicando validaciones vectorizadas de calidad de datos y generando entregables limpios en formatos ejecutivos (Word/PDF).
* **Tecnologías:** Python, Excel, Git, Pruebas Unitarias.
* **Estado:** **Completado y documentado.** [Ver código en GitHub](https://github.com/AdanAlfonso/Automatizacion-Etl-Python.git)

### 2. 🛢️ Mediciones y Consumo de Gas Natural
* **Descripción:** Herramienta analítica diseñada para la lectura de registros horarios y diarios de mantenimiento industrial, orientada a la detección temprana de irregularidades y picos de consumo atípicos.
* **Tecnologías:** Python, Pandas, Series Temporales, Data Quality.
* **Estado:** En fase de desarrollo y blindaje de datos.

### 3. 📊 Análisis de Incidentes y Métricas de Soporte TI
* **Descripción:** Modelo analítico desarrollado para procesar registros masivos de tickets de soporte técnico. Permite aislar cuellos de botella operativos, calcular tiempos de resolución y visualizar KPIs clave mediante pipelines en Python y tableros en Power BI.
* **Tecnologías:** Python, Pandas, Excel, Power BI.
* **Estado:** En proceso de anonimización de datos operativos corporativos.
