OBJETIVO: Automatizar la generación masiva de documentos a partir de datos en Excel de forma rápida, precisa y eficiente.

01. Problemática

Los procesos manuales repetitivos en la generación de reportes y conversión de formatos (como procesar información de hojas de cálculo hacia documentos ejecutivos) suelen ser propensos a errores humanos, además de consumir valiosas horas-hombre que podrían invertirse en análisis de mayor valor.

El reto principal: Diseñar un flujo automatizado y reutilizable capaz de procesar estructuras de datos estandarizadas y generar entregables limpios sin intervención manual constante.

02. Solución Propuesta

Se ideó una arquitectura basada en scripts modulares en Python encargados de leer datos tabulares, aplicar validaciones estrictas mediante pruebas unitarias y automatizar la exportación de documentos formateados.

  • Modularidad: Separación de responsabilidades entre validadores, motores de lectura y constructores de salida.
  • Pruebas Unitarias: Implementación de validaciones automáticas para garantizar la integridad de los datos procesados.
  • Estandarización: Plantillas predefinidas que aseguran consistencia visual y de contenido en cada reporte generado.

03. Implementación y Control de Calidad (Data Quality)

Para garantizar la integridad de los datos de entrada, se desarrolló un motor de validación vectorizado en Pandas. Este script no solo detecta columnas faltantes y valores nulos, sino que mapea los errores directamente a las filas reales del archivo de Excel para facilitar la depuración.

src/validators.py (Validación Vectorizada) Python 
# Validación vectorizada de calidad de datos en Pandas
for col, tipo_esperado in reglas_dinamicas.items():
    # 1. Detección de nulos mapeada a la fila real de Excel (idx + 2)
    mask_nulos = df[col].isna()
    if mask_nulos.any():
        filas_nulas = (df[mask_nulos].index + 2).tolist()
        reporte_nulos[col] = filas_nulas

    # 2. Validación y coerción de tipos sin bucles lentos
    serie_sin_nulos = df[col].dropna()
